# Шукай: Telegram-бот для новых объявлений Kufar

**[@shukajbot](https://t.me/shukajbot)** следит за поисками на Куфаре (kufar.by, auto.kufar.by, re.kufar.by) и присылает уведомления о новых объявлениях в Telegram. Подешевевшее объявление приходит ещё раз с пометкой «Цена снижена», а поднятые старые объявления не повторяются.

Сайт: **[shukaj.pages.dev](https://shukaj.pages.dev)** · по-беларуску: [shukaj.pages.dev/be](https://shukaj.pages.dev/be/) · новости: [@shukajnews](https://t.me/shukajnews)

## Что умеет бот

- **Сохранённые поиски:** собери поиск по шагам (категория, регион и города, цена, слова) или просто пришли ссылку на поиск с Куфара со всеми фильтрами.
- **Только новое:** бот помнит, что поиск уже видел, поэтому поднятые объявления не приходят дважды.
- **Снижение цены:** подешевевшее объявление из поиска приходит ещё раз со старой ценой.
- **Квартиры:** аренда или продажа, комнаты, районы, цена в долларах. [Подробнее](https://shukaj.pages.dev/kvartiry/)
- **Авто:** марка, модель, годы, пробег, коробка, двигатель, кузов. [Подробнее](https://shukaj.pages.dev/avto/)
- **Телефоны и электроника:** точная модель, поиск в заголовке, частные продавцы. [Подробнее](https://shukaj.pages.dev/telefony/)
- **Тихие часы:** ночью сообщения приходят без звука.
- **Русский и белорусский** язык.

Free бесплатный, Pro и Ultra проверяют поиск чаще и оплачиваются звёздами Telegram: [тарифы](https://shukaj.pages.dev/tarify/). Ответы на вопросы в [FAQ](https://shukaj.pages.dev/faq/), советы в [гайдах](https://shukaj.pages.dev/guides/).

## Этот репозиторий

Исходники сайта: статический сайт на [Astro](https://astro.build), Cloudflare Pages.

```bash
npm ci
npm run verify   # сборка и проверки: пары языков, длина title, ссылки, токены, структурированные данные
npm run dev
```

Тексты страниц лежат в `src/content/`, все числа планов в `src/data/plans.json`. Как устроены тексты, описано в [CONTENT.md](CONTENT.md).

<sub>Шукай не является официальным сервисом Kufar.</sub>
